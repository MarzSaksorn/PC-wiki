# PC Wiki

A beginner-friendly guide to computers — from buying your first PC to mastering your setup.

**Styling, Layout and Search System of This Project is Vibe Coded**

**Things that are not Vibe Coded in This Project is All the Infomation about Computer and Each every Article**

## Tech Stack

- **React** 19
- **React Router** 7
- **Tailwind CSS** 4
- **Vite** 6

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the dev server

```bash
npm run dev
```

Opens at `http://localhost:5173` by default.

### Build for production

```bash
npm run build
```

Output goes to the `dist/` folder.

### Preview the production build

```bash
npm run preview
```
